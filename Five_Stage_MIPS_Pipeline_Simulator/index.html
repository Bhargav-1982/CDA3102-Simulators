Program

Traced instructions: add, sub, and, or, slt, addi, lw, sw, beq. One instruction per line, operands separated by commas. Put setup lines li $reg, value first: they run at once, before CC1. syscall ends the program. Labels, # comments, .text and .globl are accepted.

Data, as in MARS: write .data, then lines such as .word 7, 9 (decimal or 0x hex), then .text before the code. The first word is at 0x10010000, the next at 0x10010004, and so on. The words are in memory before CC1.

Click a line: run to it. Click : breakpoint for Play. Press Edit to type your own program.
