# CDA 3102 Simulators

Free, browser-based simulators and tools for learning computer architecture and MIPS.
They were made for the "Computer Architecture" course and for the
"Computer Architecture Academy" YouTube channel.

There is nothing to install. Open a link and start. Google Chrome is the preferred browser.
